About Project

关于这个项目

一次从零开始的完整全栈实践

项目类别 · 模仿

模仿主流二手交易平台，
打造属于校园的闲置流转空间

以课程设计为背景，采用原生 HTML / CSS / JavaScript 构建前端界面， Node.js + Express 提供 RESTful API，MySQL 持久化业务数据。 从数据库建模、接口设计到页面交互，完整实现商品发布、浏览、 新闻资讯与图文展示等核心模块，让技术学习落在真实的业务场景里。
